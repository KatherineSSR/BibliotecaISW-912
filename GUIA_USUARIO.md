# Guía de usuario

## Iniciar sesión

1. Ingrese su correo y contraseña.
2. Seleccione **Iniciar sesión**.
3. Use el menú de la izquierda para cambiar de sección.

## Usuarios

- Seleccione **Nuevo usuario** para registrar un visitante.
- Complete los campos obligatorios y guarde.
- El sistema asignará un código de cuatro dígitos.
- Use **Editar** para actualizar los datos o cambiar el estado.

## Libros

- Seleccione **Nuevo libro** para agregar una obra.
- Complete los datos y la cantidad de ejemplares.
- Use el buscador y los filtros para encontrar libros.
- Use **Editar** para actualizar el inventario.

## Préstamos

- Seleccione **Nuevo préstamo**.
- Elija el libro, ingrese el código del usuario y seleccione la duración.
- Use **Registrar devolución** para devolver un libro.
- Si no hay ejemplares, use **Lista de espera**.

## Accesos

- Ingrese el código de cuatro dígitos del visitante.
- Agregue una observación si hace falta.
- Seleccione **Registrar ingreso**.

## Sala informática

- Seleccione una computadora libre.
- Ingrese el código del visitante y la duración.
- Seleccione **Iniciar sesión**.
- Use **Finalizar uso** al terminar.

## Cubículos

- Abra la tarjeta de cubículos en **Resumen**.
- Elija un cubículo libre.
- Ingrese el código del visitante y la duración.
- Seleccione **Iniciar turno**.
- Use **Finalizar turno** al terminar.

## Reportes

- Elija período semanal, quincenal o mensual.
- Revise los datos mostrados.
- Seleccione **Imprimir / Guardar PDF**.
